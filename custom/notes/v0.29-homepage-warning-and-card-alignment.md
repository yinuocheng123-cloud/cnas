# 版本记录：v0.29-homepage-warning-and-card-alignment

## 1. 本轮目标

本轮目标是处理两个首页细节问题：

1. 将首屏风险提示中的 `⚠` 调整为黄色，强化提示但不破坏整体克制风格。
2. 让首页卡片中已有的“查看详情”在同一组卡片内底部对齐，避免高低不齐。

本轮优先级属于：

- 首页细节收口
- 视觉层级微调
- 卡片排版对齐

## 2. 背景与上下文

本轮承接以下记录：

- `custom/notes/v0.28-footer-gap-tightening.md`
- `custom/notes/v0.27-homepage-results-matrix.md`

首页主结构已经基本收口，当前进入的是细节打磨阶段。用户本轮反馈非常具体，说明首页主体方向已基本确认，剩下的问题集中在视觉提示和卡片排版的一致性。

## 3. 问题分析

当前有两个独立但都影响精致度的问题：

1. 风险提示中的 `⚠` 与正文同色，提示存在，但视觉提醒不够明确。
2. 解决方案卡片的文案长短不一，导致“查看详情”在不同卡片中的垂直位置不一致，看起来不够整齐。

真正的问题不是缺少内容，而是视觉信号和排版基线还不够稳。

## 4. 候选方案比较

### 方案一：只改颜色，不处理卡片按钮位置

优点：

- 改动小

缺点：

- 首页卡片底部仍会显得不齐

放弃原因：只能解决一半问题。

### 方案二：分别处理提示图标颜色和卡片底部动作位

优点：

- 能同时解决视觉提醒和对齐问题
- 不需要新增组件
- 不影响现有文案结构

缺点：

- 需要轻微调整 `HeroSection` 的 `riskNotice` 类型

最终选择原因：改动仍然很小，但能直接命中用户反馈。

## 5. 最终决策

本轮最终采用以下方式：

1. 将 `HeroSection` 的 `riskNotice` 从 `string` 放宽为 `React.ReactNode`。
2. 在首页首屏传入带黄色图标的风险提示内容。
3. 为 `SolutionCard` 中的“查看详情”增加 `mt-auto`，让它在等高卡片中自动贴到底部对齐。

## 6. 具体实现

本轮修改文件如下：

- `components/HeroSection.tsx`
  - 放宽 `riskNotice` 类型，支持单独给图标着色

- `app/page.tsx`
  - 将首页首屏风险提示改为黄色 `⚠` + 原文案

- `components/SolutionCard.tsx`
  - 将“查看详情”改为底部自动对齐

## 7. 本轮优点

本轮带来的正向效果：

- 首屏风险提示更容易被扫到
- 首页方案卡片底部动作位更整齐
- 不新增结构，不改变首页内容逻辑
- 改动集中，影响范围可控

## 8. 本轮缺点与代价

当前方案的已知取舍：

- 本轮只处理首页中已有“查看详情”的方案卡片，没有扩展到所有无动作卡片
- `riskNotice` 改为 `React.ReactNode` 后更灵活，但也意味着调用方可以传入更复杂的内容，后续需继续保持克制

## 9. 验证与结果

本轮计划执行以下验证：

- `npm run typecheck`
- `npm run build`

验证目标：

- `HeroSection` 类型调整不引入错误
- 首页构建结果保持稳定

## 10. 本轮结论

本轮最重要的结论是：首页高级感的后半段主要来自细节一致性。图标提示是否有层次、卡片动作位是否齐线，这类小问题会直接影响整体完成度。

## 11. 下一轮建议

1. 如继续打磨首页，可检查“按典型问题判断风险”那组卡片是否也需要统一底部动作位。
2. 如用户还想继续收紧，可再看首屏按钮组与风险提示之间的纵向距离。
