# 版本记录：mobile-platform-homepage-refactor

## 1. 本次目标

本轮目标是基于 `www.cnaszhinan.com` 电脑版现有内容和定位，重构主站手机端首页 UI。

本轮只处理主站 `C:/Users/Administrator/Documents/New project 10/`，不处理 `path.cnaszhinan.com` 成交页，不把成交页逻辑搬到主站首页，不做强销售落地页。

目标定位是：`CNAS认可指南 = CNAS行业服务平台`。手机端要体现深蓝高级风、金色点缀、克制、专业、平台感和行业服务入口感。

## 2. 参考 UI 方向

用户提供的参考图只作为视觉气质参考，不逐字照抄文字，不照搬成交页结构。

本轮继承的视觉方向：

- 深蓝背景承载平台首屏。
- 金色作为少量重点点缀。
- 大标题、充足留白、卡片化模块。
- 内容以平台能力和行业问题为主，不以扫码或表单作为首屏核心。
- 咨询入口保留，但呈现为“平台服务入口”，避免强销售压迫感。

- 主站已有 `/diagnosis` 信息收集和线索提交链路，本轮不改接口、不改后台、不改数据库。

## 4. 问题分析

修改前手机端主要问题：

- 首屏仍偏“风险判断工具”，平台定位不够强。
- 手机端内容顺序没有完整呈现“平台定位 → 行业问题 → 平台能力 → 路径判断 → 顾问入口 → 内容入口 → FAQ → 后期维护”的平台节奏。
- 咨询入口和二维码存在，但更像普通转化入口，缺少平台服务感。
- 最新行业内容在手机端没有被独立凸显。

核心矛盾：需要让手机端更像行业服务平台入口，同时不破坏电脑版首页和现有业务逻辑。

## 5. 候选方案比较

### 方案一：重做全站首页

优点：视觉统一度最高。

缺点：会影响电脑版主体结构，容易重复 v1.2 之前“桌面首页成交页化”的问题。

结论：放弃。

### 方案二：只改现有移动端卡片样式

优点：改动较小。

缺点：无法满足本轮要求的移动端顺序和平台定位表达。

结论：不足以满足目标。

### 方案三：新增移动端专属首页层，桌面端保持原结构

优点：手机端可以形成独立平台体验，电脑版主体稳定；不改接口、不改后台、不改 SEO 生成逻辑。

缺点：移动端和桌面端存在一定双轨内容维护成本。

结论：采用。
