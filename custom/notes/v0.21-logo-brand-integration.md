# 版本记录：v0.21-logo-brand-integration

## 1. 本轮目标

本轮目标是为网站补齐正式品牌识别，把用户提供的 `cnaslogo.png` 接入站点头部，并统一站点名称与定位文案。

本轮优先级属于：

- 品牌识别补充
- 可上线信息完善
- 最小改动接入

## 2. 背景与上下文

本轮承接以下记录：

- `custom/notes/v0.20-homepage-spacing-tightening.md`
- `custom/notes/v0.13-design-token-system.md`

在此前版本中，网站已经基本完成内容、诊断与上线链路，但品牌入口仍然只有纯文字，缺少可识别的 Logo。用户本轮明确提供了 Logo 图片，并明确站点名称为“CNAS认可指南”，站点定位为“CNAS专业知识与认可解决方案平台”。

本轮不做导航结构调整，不做 UI 改版，只把品牌识别补齐到现有头部和站点元信息中。

## 3. 问题分析

修改前主要有三个问题：

1. Header 只有文字品牌入口，辨识度不足。
2. 站点名仍使用较长的描述性名称，不适合作为统一品牌主名。
3. 用户提供的 Logo 原图带有较大白边，如果直接使用，会在头部显得过小且占位不自然。

真正需要解决的不是“多加一个图片”，而是让 Logo 在现有克制风格下自然融入，同时把品牌名和定位文案统一起来。

## 4. 候选方案比较

### 方案一：直接使用原始 PNG 作为头部 Logo

核心思路：把用户提供的 PNG 直接复制进项目，在 Header 中显示。

优点：

- 实现最快
- 不需要额外处理图片

缺点：

- 原图白边过大，头部显示时会显得 Logo 很小
- 导航区域会出现不必要的视觉空白
- 品牌入口不够精致

放弃原因：虽然简单，但显示效果不适合当前头部空间。

### 方案二：先裁切 Logo，再接入头部与品牌文案

核心思路：先从原图中裁出适合网页头部使用的横向版，再在 Header 中作为主品牌图，辅以较轻的定位文字。

优点：

- 保留用户提供的完整品牌视觉
- 头部显示尺寸更合适
- 不需要改动导航结构

缺点：

- 需要额外生成一份站内静态资源

最终选择原因：更符合现有设计风格，也更适合作为正式上线品牌入口。

## 5. 最终决策

本轮最终采用“裁切原图 + 统一品牌口径”的方案：

1. 将用户提供的 `cnaslogo.png` 裁切为适合网页头部的横向 Logo
2. 把裁切后的文件放入站点静态资源目录
3. 在 Header 中使用 Logo 图片替换原文字品牌位
4. 将站点主名称统一为“CNAS认可指南”
5. 将站点定位统一为“CNAS专业知识与认可解决方案平台”

## 6. 具体实现

本轮修改文件如下：

- `public/brand/cnas-logo.png`
  - 由用户提供的原始 PNG 裁切生成，去掉大面积白边，保留横向品牌主视觉

- `components/Header.tsx`
  - 接入 `next/image`
  - 用 Logo 替换原纯文字品牌入口
  - 在 Logo 下方增加较轻的定位文案

- `components/SiteHeader.tsx`
  - 同步品牌入口写法，避免后续启用该组件时出现品牌不一致

- `components/Footer.tsx`
  - 将页脚品牌名统一为“CNAS认可指南”
  - 用一句话明确站点定位

- `lib/seo.ts`
  - `siteName` 改为“CNAS认可指南”
  - `defaultPageTitle` 改为“CNAS认可指南｜专业知识与认可解决方案平台”

## 7. 本轮优点

本轮带来的正向效果：

- 网站有了明确的品牌识别入口
- 站点名称更短、更稳定，适合作为长期品牌主名
- 品牌定位仍然保留在头部和页脚，不会丢失专业平台属性
- 改动集中在品牌层，不影响内容结构与组件体系

## 8. 本轮缺点与代价

本轮也有明确代价：

- 当前只补齐了头部、页脚和 SEO 口径，没有扩展到 favicon、分享图等更完整的品牌资产体系
- Logo 资源是基于用户提供图片裁切得来，不是矢量文件，后续如果需要更高分辨率适配，最好补一份原始矢量稿
- Header 使用的是完整字标 Logo，因此在极小屏幕下不能无限放大，仍需控制显示宽度

## 9. 验证与结果

本轮完成后计划执行以下验证：

- `npm run typecheck`
- `npm run build`

验证目标：

- 品牌组件改动不引入类型错误
- `next/image` 静态资源接入正常
- 站点可以继续正常构建

## 10. 本轮结论

本轮最重要的结论有三点：

1. 当前站点已经从“内容原型”进一步收口到“具备正式品牌识别的专业平台”。
2. 对于头部 Logo，先裁切再接入，比直接使用原图更符合当前克制风格。
3. 品牌名与定位应分层表达：品牌名短，定位语轻，避免把长描述继续当主标题使用。

## 11. 下一轮建议

1. 如需进一步完善品牌体系，可补 favicon、Open Graph 分享图和浏览器标签图标。
2. 若后续拿到矢量 Logo，建议替换当前 PNG 版本，以提升高分屏显示质量。
3. 可在 `/about` 页中同步补充“CNAS认可指南”的品牌说明，增强整站一致性。
