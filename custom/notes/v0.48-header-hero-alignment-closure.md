# 版本记录：v0.48-header-hero-alignment-closure

## 1. 本轮目标

本轮只处理首页顶部和首屏的最后一轮对齐收口，重点解决：

- Header Logo 显示不完整
- Header 平台副标题与右侧导航区域底边关系不稳
- Hero CTA 下方 3 个行业 pills 过于冗余
- 去掉 pills 后，Hero 左右两侧高度需要重新匹配
- 右侧四宫格内部行距仍略显松散

本轮属于：

- 首页顶部收口
- Hero 左右对齐修正
- 首屏信息减法

## 2. 背景与上下文

本轮承接：

- `custom/notes/v0.47-homepage-visual-closure.md`

延续结论：

- 首页首屏仍保持“左侧主叙事 + 右侧风险判断”结构
- 不增加新模块，只做现有结构内部对齐和节奏收口
- Hero 右侧四宫格继续保留，不回退为空白区

## 3. 问题分析

表面现象：

- Logo 因显示宽高控制问题，视觉上被裁切
- 平台副标题位置偏上，和右侧导航区域关系不稳定
- Hero CTA 下方的 3 个行业 pills 拉高了左侧高度，也削弱了首屏克制感
- 去掉 pills 之后，右侧矩阵会显得偏长，需要重新拉平两侧高度

核心矛盾：

当前问题不是内容不够，而是首屏底边关系和顶部品牌区没有收干净，导致整体气质还不够像正式发客户的版本。

## 4. 候选方案比较

### 方案 A：只删掉 3 个 pills

优点：

- 改动最小

缺点：

- 左右高度关系仍然不一定自然
- Header Logo 与副标题问题仍然存在

结论：

放弃。

### 方案 B：同步收口 Header、Hero 左右底边和风险卡行距

优点：

- 一次解决顶部与首屏的主要视觉问题
- 不需要重构结构
- 更符合“上线前最后一轮精修”的目标

缺点：

- 涉及 Header、Hero、RiskCard 三处联动调整

结论：

采用。

## 5. 最终决策

最终采用以下处理方式：

1. 调整 Header Logo 显示方式，确保完整可见
2. 将 Header 平台副标题改为更稳定的底部对齐关系
3. 删除 Hero CTA 下方 3 个行业 pills
4. 将 Hero 桌面端左右容器改为更接近同底对齐
5. 微调右侧风险卡内部行距，压缩矩阵高度

## 6. 具体实现

### `components/Header.tsx`

- 重写为稳定版 Header
- Logo 改为 `object-contain`
- 平台副标题改为与 Logo 同组，并在桌面端使用更贴近底边的对齐方式

### `app/page.tsx`

- 删除 Hero CTA 下方的 3 个行业 pills
- 去除首页对 `getFeaturedIndustries` 的依赖

### `components/HeroSection.tsx`

- 桌面端 balanced Hero 从单纯顶部对齐改为更接近左右同底对齐
- 左侧正文行高略收紧
- 右侧风险容器改为 `self-end`

### `components/RiskEntryCard.tsx`

- 收紧数字与标题之间的间距
- 略微压缩标题和说明行高

## 7. 本轮优点

- Header Logo 视觉更完整
- Header 副标题与右侧区域关系更自然
- Hero 左侧信息更克制，首屏不再被多余 pills 拉长
- 右侧四宫格与左侧去掉 pills 后的高度更接近

## 8. 本轮缺点与代价

- 这轮主要收口桌面端首屏关系，移动端并未大改
- `typecheck` 受到 `.next/types` 缺失影响，需要在 dev 或 build 后再执行更稳定

## 9. 验证与结果

已执行：

- `npm run build` 通过
- 本地 `http://127.0.0.1:3000/` 返回 `200`

补充说明：

- `npm run typecheck` 本轮失败原因不是业务代码报错，而是 `.next/types` 被清理后，`tsconfig` 仍包含 `.next/types/**/*.ts`

## 10. 本轮结论

首屏的高级感很多时候不是来自新增设计，而是来自删掉多余信息、拉齐底边关系、修正品牌区显示细节。

这轮之后，首页顶部与首屏已经更接近正式发客户的状态。

## 11. 下一轮建议

1. 用浏览器继续复核 1440 / 1536 宽度下 Header 与 Hero 的真实视觉关系
2. 如仍觉得右侧矩阵偏高，可优先再压说明文字行高，而不是继续缩卡
3. 如需继续收口，下一步优先处理 Footer 与 CTA 区，统一顶底留白与按钮节奏
