# 版本记录：v0.49-header-logo-replacement

## 1. 本轮目标

本轮目标是按用户要求替换 Header 品牌区：删除 Header 中单独展示的“CNAS专业知识与认可解决方案平台”文字，并用用户提供的新 logo 图替代原有品牌展示。

本轮目标属于视觉资产替换和 Header 品牌区最小改动，不调整导航结构，不重构 Header，不修改首页 Hero 与其它页面内容。

## 2. 背景与上下文

本轮承接 `custom/notes/v0.48-header-hero-alignment-closure.md`。上一轮已经对 Header Logo 显示完整性和副标题底边对齐做过收口，但本轮用户明确要求去掉副标题文字，并把新 logo 作为品牌主体。

## 3. 问题分析

当前 Header 中原本存在两部分品牌信息：

1. `/brand/cnas-logo.png` 图片。
2. 图片右侧的文字副标题“CNAS专业知识与认可解决方案平台”。

新 logo 图片本身已经包含“CNAS认可指南”和“CNAS专业知识与认可解决方案平台”等信息，如果继续保留右侧文字，会产生重复表达，也会让 Header 品牌区显得拥挤。

## 4. 候选方案比较

方案一：只替换图片，不删除右侧文字。

优点是改动更少。缺点是新 logo 内部已经包含平台副标题，再保留外部文字会重复，违背用户“这几个字直接去掉”的要求。因此放弃。

方案二：替换图片并删除右侧文字。

优点是符合用户要求，也能让 Header 品牌区更简洁。最终选择该方案。

## 5. 最终决策

将用户提供的 `C:\Users\Administrator\Desktop\cnaslogo.png` 裁掉外侧大面积白边后写入 `public/brand/cnas-logo.png`，并在 `components/Header.tsx` 中删除副标题文字，仅保留图片 logo。

## 6. 具体实现

修改 `public/brand/cnas-logo.png`：使用用户提供的新 logo，保留图形和文字内容，仅裁掉外侧白边以适配 Header。

修改 `components/Header.tsx`：

- 删除原本位于 logo 右侧的副标题文字。
- 更新 `Image` 宽高为新 logo 裁切后的比例。
- 将品牌链接容器改为居中对齐，避免删除文字后仍保留旧的底边对齐关系。

## 7. 本轮优点

Header 品牌区更简洁，不再重复展示平台副标题。新 logo 作为单一品牌入口，视觉表达更集中，也减少了顶部导航区的信息负担。

## 8. 本轮缺点与代价

新 logo 原始图片外侧留白较大，本轮通过裁白边处理提升 Header 适配性。该处理不会改变 logo 内容，但如果后续有正式透明底或矢量版本，应优先替换为正式品牌资产。

## 9. 验证与结果

本轮需要执行：

- `npm run typecheck`
- `npm run build`
- 本地首页访问验证

## 10. 本轮结论

Header 已从“图片 + 外置副标题”改为“单一 logo 品牌入口”，符合用户要求，也更适合当前克制、专业的平台定位。

## 11. 下一轮建议

1. 如果用户提供透明底或 SVG logo，建议替换当前 PNG。
2. 用浏览器复核 1440px 和移动端 Header，确认 logo 尺寸是否需要再微调。
3. 如桌面端 logo 仍偏小，可优先微调 `components/Header.tsx` 中图片高度，而不是恢复文字副标题。
