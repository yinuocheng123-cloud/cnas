# 版本记录：v0.31-navigation-ice-blue-state

## 1. 本轮目标

本轮目标是把网站导航栏的悬停态和选中态颜色，从上一轮的主蓝色调整为用户指定的浅冰蓝 `#4ECDC4`，同时保持默认未点击状态为黑色。

本轮优先级属于：

- 导航交互微调
- 配色精修
- 最小样式调整

## 2. 背景与上下文

本轮承接以下记录：

- `custom/notes/v0.30-navigation-interaction-state.md`

上一轮已经完成了导航交互逻辑统一：

- 默认黑色
- 悬停蓝色
- 当前页保持蓝色

这轮不是重做交互，而是在保持交互逻辑不变的前提下，把颜色进一步调整为更轻、更克制的浅冰蓝。

## 3. 问题分析

当前问题不是状态不明确，而是颜色还不完全符合用户预期。上一轮使用的是项目主蓝色，交互逻辑是对的，但用户现在明确要求换成 `#4ECDC4`。

因此本轮核心不是改行为，而是改状态色本身。

## 4. 候选方案比较

### 方案一：直接继续使用 `text-primary`

优点：

- 与现有设计 token 更一致

缺点：

- 不满足用户指定颜色

放弃原因：与当前明确需求不一致。

### 方案二：仅在导航组件中把激活态和 hover 态改为 `#4ECDC4`

优点：

- 改动最小
- 不影响站内其他蓝色用法
- 精准命中当前需求

缺点：

- 颜色先以局部类名写入，尚未抽成全局 token

最终选择原因：最稳妥，也最符合“只修改导航交互色”的边界。

## 5. 最终决策

本轮最终采用以下方式：

1. 保持导航默认态为 `text-ink`。
2. 将 `Header` 和 `SiteHeader` 的 hover 态改为 `text-[#4ECDC4]`。
3. 将当前激活项和下拉箭头的激活态同步改为 `#4ECDC4`。

## 6. 具体实现

本轮修改文件如下：

- `components/Header.tsx`
  - 将导航链接 hover / active 颜色改为 `#4ECDC4`
  - 将下拉箭头 hover / active 颜色同步改为 `#4ECDC4`

- `components/SiteHeader.tsx`
  - 将导航链接 hover / active 颜色改为 `#4ECDC4`

## 7. 本轮优点

本轮带来的正向效果：

- 导航状态逻辑保持不变
- 颜色更贴近用户期待
- 比主蓝色更轻，视觉上更清爽
- 改动只局限在导航，不影响其他按钮和内容区

## 8. 本轮缺点与代价

当前方案的已知取舍：

- `#4ECDC4` 目前只在导航中局部使用，尚未沉淀为全局 token
- 若后续多个位置都想复用这个色值，可能需要再统一抽取

## 9. 验证与结果

本轮计划执行以下验证：

- `npm run typecheck`
- `npm run build`

验证目标：

- 导航颜色类名调整不影响类型
- 构建结果保持稳定

## 10. 本轮结论

本轮最重要的结论是：导航交互逻辑已经稳定，当前更值得做的是颜色精修。将选中与悬停色替换为更轻的浅冰蓝后，导航会更贴近“专业、清爽、克制”的平台气质。

## 11. 下一轮建议

1. 如果你后续想让整站交互色更统一，可以再决定是否把 `#4ECDC4` 抽成新的全局 token。
2. 如果只想把它限定在导航，这一版已经足够干净，不建议继续加装饰。
